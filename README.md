# Guitar Score Editor

브라우저에서 오선 악보와 기타 TAB을 함께 편집하는 사보 앱입니다. 별도 설치 없이 GitHub Pages에서 실행됩니다.

## 구현된 기능

- 오선 음표와 TAB 숫자의 양방향 연동
- TAB 숫자 직접 선택, 숫자 키 프렛 변경, 화살표 줄/음표 이동
- 점음표, 쉼표, 꾸밈음, 타이, 오선·TAB 슬러, 클래식 기타 바레 범위
- 4개 성부와 성부별 색상 표시
- 2/4·3/4·4/4·5/4·6/8·9/8·12/8 박자표와 박 단위 비밍
- 픽업 마디(못갖춘마디): 원하는 마디에 별도 박자표 지정(마디 번호에서 제외), MusicXML 불러오기/내보내기 지원
- 음표 입력 시 직전 음과 가장 가까운 옥타브 자동 선택, 선택한 쉼표도 숫자 키로 길이 변경
- Enter 키 마디 줄바꿈, A4/A3/Letter/화면 페이지 크기
- 제목·작사·작곡 정보, MusicXML 불러오기/내보내기, 벡터 PDF 내보내기(jsPDF·svg2pdf.js)
- Shift+화살표 범위 선택, 마디 복사/붙여넣기(Ctrl+C/V), Ctrl+Z 실행 취소
- 브라우저 자동 저장: 새로고침·뒤로 가기 후에도 작업 유지
- 클래식 기타·통기타·일렉 기타·피아노 문서 선택
- 한글 IME 상태에서도 물리 키 A–G 음표 입력

`index.html`을 열거나 정적 웹 서버로 저장소 루트를 제공하면 실행할 수 있습니다.
